# Creating Markdown Files on Windows and Mac

## Windows

You can create a `.md` file directly in Slack from copied content:

1. Copy the Markdown content with `Ctrl + C`.
2. In Slack, click the message box and press `Ctrl + Shift + Enter`. This opens **Create a text snippet**.
3. Paste the content with `Ctrl + V`.
4. Give it a filename such as `README.md`.
5. Select **Markdown** as the file type if available.
6. Click **Create Snippet** and share it in the channel.

You can also type `/snippet` in Slack to open the snippet creator.
